## Selected engineering projects

Start with **1Context** for systems architecture or **Guardian Backend** for backend engineering. Each repository has a block diagram, code entry points, engineering decisions, and explicit validation limits.

| Project | Engineering focus |
| --- | --- |
| [1Context](https://github.com/jackieoliver/1context-platform) | Local context platform: Rust services, native macOS shell, inspectable wiki, and durable agent-workflow experiments. **Rust, Swift, Python, JavaScript.** |
| [Guardian Backend](https://github.com/jackieoliver/guardian-backend) | Recording ingestion, archive processing, canonical storage, and per-user workspaces. **Python, FastAPI, GCP, Swift.** |
| [Capture & hand tracking](https://github.com/jackieoliver/egocentric-capture) | Camera control, recording sessions, telemetry, and hand-pose processing. **Python, Swift, GoPro, Apple Vision.** |
| [Guardian Evidence Pipeline](https://github.com/jackieoliver/guardian-evidence-pipeline) | Source provenance, temporal scenes, cross-device alignment, and deterministic episode construction. **Python, SQLite.** |
| [AI Reader](https://github.com/jackieoliver/ai-reader-native) | Streaming text-to-speech, cancellation, audio buffering, and native macOS controls. **Swift, WebSockets, AVAudioEngine.** |
| [Phonecapture](https://github.com/jackieoliver/phonecapture) | Android USB-camera recording, local media transfer, and a native desktop importer. **Java, Android, Swift.** |

These are curated code editions. Private recordings, context archives, credentials, and deployment configuration are excluded. Hardware and native applications have setup requirements; the READMEs distinguish verified tests from unverified integrations.
